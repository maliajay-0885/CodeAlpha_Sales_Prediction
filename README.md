# CodeAlpha Sales Prediction

## Project Overview
This project predicts product sales using advertising expenditure data and Linear Regression.

## Objectives
- Explore the relationship between advertising channels and sales.
- Train a Linear Regression model.
- Evaluate model performance.
- Visualize actual and predicted sales.

## Dataset
The dataset contains 200 records and includes TV, Radio, Newspaper, and Sales columns, along with an index column.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Model Performance
- Mean Absolute Error (MAE): 1.461
- Root Mean Squared Error (RMSE): 1.782
- R-squared Score: 0.899

## How to Run
Install dependencies:

`python -m pip install pandas matplotlib scikit-learn`

Run the project:

`python sales_prediction.py`

## Outputs
The `outputs` folder contains prediction results, an actual-versus-predicted graph, and advertising coefficient analysis.

## Conclusion
The Linear Regression model achieved an R-squared score of 0.899 on the test set. The results illustrate how advertising expenditure can be used to estimate sales in this dataset."# CodeAlpha_Sales_Prediction"
